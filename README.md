Calculadora de IMC em Java ☕

📌 Sobre o projeto

Este projeto é uma calculadora de Índice de Massa Corporal (IMC), desenvolvida em Java como parte dos meus estudos em programação.

O programa solicita o peso e a altura do usuário, realiza o cálculo do IMC e apresenta o resultado com duas casas decimais.

🛠️ Tecnologias utilizadas

Java

Apache NetBeans

Maven

💻 Funcionalidades

Entrada de dados pelo usuário

Cálculo do Índice de Massa Corporal

Exibição do resultado formatado

🧮 Fórmula utilizada

IMC = peso / (altura × altura)

🎯 Objetivo

Praticar conceitos fundamentais de programação, como variáveis, tipos de dados, entrada de informações, operações matemáticas e formatação de resultados.

👩‍💻 Desenvolvimento

Projeto desenvolvido durante meus estudos em Análise e Desenvolvimento de Sistemas, como parte da construção do meu portfólio no GitHub.
